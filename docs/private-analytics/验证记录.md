验证日期：2026-09-29。开发分支：`codex/private-analytics`。环境：本地 Node.js 22.16.0、Next.js 15.5.20、SQLite。

## 自动检查

- `npm run test:analytics`：10项测试全部通过，覆盖整段/页面UV、PV重试幂等、跨日去重、多标签会话及有效区间并集、时长五档边界、会话空闲超时、迟到区间、持久共享限流、撤销/过期、非法参数、异常计时、慢哈希。
- `npm run check`：ESLint、TypeScript及内容校验通过。
- `npm run build`：生产构建通过，公共课程/知识库/SQL路由保留，后台和数据API按动态路由构建。
- 生产模式本地运行：即使存在本地SQLite配置，采集开关仍为关闭，使用正式域名的同源头提交登录返回503；不会误启用生产后台。后台页面返回私有无缓存及noindex响应头。

## HTTP联调

- 未登录统计接口401；错误密码401；外站Origin403。
- 正确密码登录200，Cookie包含HttpOnly及SameSite=Strict；查询返回private/no-store。
- 公共浏览事件204；重复提交同事件不增加PV；后台路径400；外站采集403；机器人不写入访问数据。
- 页面筛选仅改变对应指标，排行榜保留全站有数据页面；非法日历日期400。
- 退出200，撤销后的会话再读统计401。
