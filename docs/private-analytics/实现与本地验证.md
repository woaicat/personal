# 私人访问统计：当前实现与本地运行

## 当前状态

在 `codex/private-analytics` 分支进行功能开发，未推送生产，未创建云端数据库或付费订阅；所有者已自行注册并登录Turso。现有主站发布流程不变。

已实现密码登录、7天管理员会话、退出撤销、私有统计接口、统一埋点、时间与页面筛选、UV/PV总览和趋势、全部有数据页面排行榜、单次访问时长、属地与设备分布。默认每30秒刷新后台；埋点有效计时每15秒提交。后台直接访问 `/admin`，无公开导航入口。

本地数据写入 SQLite `.local/private-analytics.sqlite`，不是写死的图表数字。所有页面明确显示“本地测试数据”，本地采集必须显式开启。地域暂为“未知”，不能用本地请求推断真实生产访客属地。

已实现Turso libSQL异步适配器，尚未配置或验证真实云端连接。`local-sqlite` 在生产/Vercel环境仍强制关闭，不写Vercel临时磁盘。Turso连接要求专用URL、Token和显式数据模式；Production要求 `production`，开发/Preview只允许测试模式。没有完整配置或初始化库时关闭采集/后台，接口503。完整接入步骤见[Turso接入与上线](./Turso接入与上线.md)。

## 本地运行

需要 Node.js 22.13 或以上（已在22.16.0验证）。使用内置 `node:sqlite`，在当前Node版本仍会输出实验性功能提示，数据库不需要额外 npm 包或外部服务；图表使用Apache ECharts 6.1开源依赖，不涉及账号或服务费用。[Node SQLite文档](https://nodejs.org/api/sqlite.html)

```sh
npm run analytics:setup
npm run dev
```

设置脚本在本地终端隐藏输入密码，要求至少12个字符；写入的 `.env.local` 只有带盐慢哈希和随机密钥。它保留原有其他环境变量，不改生产设置。密码哈希采用内置 scrypt：N=131072、r=8、p=1、64字节输出、256MiB最大内存，符合OWASP针对scrypt的最低建议。使用内置算法减少额外依赖。[密码存储依据](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)

开发检查使用 `node scripts/analytics-setup.mjs --local-preview` 生成一次性随机测试密码。仅此明确的预览模式会把临时凭据保存到 `.local/preview-password.txt`，权限0600，Git忽略；它不是生产密码，也没有写入源码、浏览器持久存储或日志。后续运行交互设置脚本改为自己的本地密码，删除此临时文件。设置脚本轮换管理员会话密钥，保留匿名统计密钥，避免修改密码导致访客去重口径改变。

访问 `http://127.0.0.1:3000/admin`，未登录会跳到登录页。登录后默认排除该浏览器访问主站产生的数据；验证埋点应使用未登录的另一个浏览器环境。尊重DNT，自动化机器人默认排除。不存在默认密码、自动登录旁路或“知道网址即可读取”的公开API。

## 配置与数据

| 配置 | 当前用途 |
| --- | --- |
| ANALYTICS_STORAGE | local-sqlite（本地）或turso（持久云端） |
| ANALYTICS_DATA_MODE | test或production；生产部署必须显式production |
| TURSO_DATABASE_URL / TURSO_AUTH_TOKEN | 专用libSQL数据库连接及Token，只在服务端使用 |
| ANALYTICS_PREVIEW_ENABLED | Preview采集独立开关，默认关闭 |
| ANALYTICS_SQLITE_PATH | 本地数据库位置 |
| ANALYTICS_ENABLED=true | 总开关 |
| ANALYTICS_DEV_ENABLED=true | 明确允许开发环境测试采集 |
| ADMIN_PASSWORD_HASH | scrypt哈希；写env文件时需转义分隔符 `$`，设置脚本自动处理 |
| ADMIN_SESSION_SECRET | 会话校验密钥 |
| ANALYTICS_ID_SECRET | 匿名ID及限流来源的独立HMAC密钥 |

`.env.local`、`.local/`、数据库、临时密码、测试截图均不提交。匿名访客只存HMAC摘要，不存原始IP和完整UA；仅保存设备类别。数据库中管理员会话只存随机Cookie令牌的校验摘要。Cookie为HttpOnly、SameSite=Strict、主机限定，生产选项包含Secure。

SQLite建表在适配器首次连接时执行，版本为1，包含浏览、会话、有效区间、幂等事件、管理员会话、共享限流和计时质量记录。写入用事务，跨连接限流持久化；无效时长不伪装为零秒，排除对应访问并显示排除数量。浏览有效但没有有效停留区间的访问仍合法进入首档。

## 代码边界

- `lib/private-analytics/repository.ts`：存储契约。统一同步/异步存储契约；API及鉴权均等待数据库操作完成。
- `lib/private-analytics/turso.ts`、`store.ts`、`schema.json`：Turso事务与共享原子限流、懒连接及共享结构；云端库由显式初始化脚本建表，不在公开请求/构建中建表。SDK锁定0.17.4，经本地并发验证；0.18.0本地驱动在锁冲突后出现提交/锁异常，升级前需回归。运行时采用Web子入口连接云端，不使用原生文件驱动。
- `lib/private-analytics/sqlite.ts`：本地适配器与建表，不作为Vercel生产方案。
- `aggregate.ts`：去重、北京时间边界、趋势桶、时长并集及五档分布。总UV不累加日UV或页面UV。
- `auth.ts`、`password.ts`、`http.ts`：服务端鉴权、慢哈希、来源校验、体积限制及私有响应。
- `public/private-analytics.js`：共享匿名SDK；公共布局仅安装一次，独立静态页面 `act.html` 使用同一脚本。页面浏览及活动事件分开，不因心跳增加PV。
- `pages.ts`、`static-paths.json`：公共页面规范路径和名称；课程、SQL课程及已发布Markdown文章按现有内容注册表校验，404和未发布路由不计入。
- `components/private-analytics/`、`app/admin/`：简洁登录、统计页面、图表空态/错误态及响应式样式。全部五张图使用 Apache ECharts：`EChart.tsx` 只处理React生命周期、ResizeObserver和销毁，`Charts.tsx` 提供库标准option，不再维护自绘SVG或CSS柱状图。ECharts按需注册折线、柱状、坐标系、tooltip和SVG渲染器，并在后台动态加载，不进入公共页面的首次包。[ECharts按需导入说明](https://echarts.apache.org/handbook/en/basics/import/)

## 本地模拟数据

完成本地配置后，运行 `npm run analytics:demo`，生成截至当天、覆盖430天的模拟访问记录：约三万次会话，十余个真实页面名称，包含增长、每周波动、活动高峰、回访及不同UV/PV比例，覆盖五档访问时长、多个属地与桌面/手机/平板设备。模拟记录写入本地SQLite，所有图表和筛选继续走真实聚合逻辑，界面仍标识“本地测试数据”；历史日期和属地均为虚构演示。

脚本仅能操作项目 `.local` 目录内已有的SQLite数据库，拒绝生产及Vercel环境，不创建服务或发送网络请求。重复运行只替换带 `demo-analytics-v1:` 标记的模拟记录，保留真实本地访问和管理员登录会话。运行 `npm run analytics:demo -- --clear` 可单独清除模拟记录。数据库文件被Git忽略，不提交或迁移到生产。

## 新页面的统计规范

1. 公共App Router页面自动使用全局SDK，不重复安装，不手写PV事件。
2. `predev`、`prebuild`运行路由扫描脚本，自动注册有效静态公共页面。新页面创建后重启开发服务；打包时会更新注册表。可手动运行 `node scripts/analytics-routes.mjs`。
3. 在 `pages.ts`补充友好名称；已有动态课程、SQL课和Markdown文章直接沿用内容标题。新类型动态路由需增加校验/名称解析，避免把任意未知URL当有效页面。未补名称的有效静态页面用路径兜底。
4. URL query/hash变化不单独增加PV。新路径、刷新、重新进入分别新增浏览；30分钟无有效活动后再次活动创建新访问。
5. 验收首次打开、站内切换、刷新、锚点、隐藏/失焦暂停和恢复。管理员访问、后台、API、404和静态资源排除；未登录公共静态HTML使用同一SDK。
6. 删除或改名页面不删除已有历史记录。路径迁移若要合并身份，应在注册表显式维护映射。

悬浮趋势图时显示日期、UV和PV；排行榜显示页面名称、路径、UV和PV；时长、属地和设备显示分类及对应统计单位。卡片采用ECharts标准HTML tooltip，移动端支持触摸点击，离开后隐藏；图表随容器自动调整大小。

排行榜始终为同一时间范围内全站页面，页面筛选控制其他图表。页面选项来自有数据记录，可按名称/路径查找。选中页面换时间后无数据仍保留选项。图表异常显示错误，不把服务不可用画成零访问。

## 上线前仍需处理

Vercel函数磁盘不适合长期保存数据库，[运行时依据](https://vercel.com/docs/functions/runtimes)。如果继续使用Vercel部署，本模块需一个持久化数据库；不需要额外的账号登录服务或独立埋点服务。所有者已选定Turso Free，并完成账号注册；下一步创建libSQL测试库、通过隐藏输入配置Token并验证真实连接，不增加付费服务。具体额度、地区、备份与超额设置仍需在账号核对。

如果改为已有服务器自托管并具有持久磁盘，也可评估SQLite长期运行，但需对应的磁盘备份、单实例部署和运维设置。目前没有迁移部署架构。

生产工作包括：真实云端连接与性能验证、正式库初始化、生产域名与环境隔离、可信部署入口的IP国家/省区编码解析和中文映射、异常采集观测、管理员正式密码与密钥、正式采集起点、部署授权及上线验证。历史Vercel Analytics不会混入这套统计；之前没有本模块埋点的数据无法补采。
