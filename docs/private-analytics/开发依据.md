# 私人网站访问统计后台｜开发依据

版本：v1.0 草案 · 2026-09-29

本文件是后续页面、埋点、接口、数据库和验证工作的共同依据。功能开发已完成本地验证，现已适配Turso libSQL；真实云端测试连接及独立正式库初始化已验证，所有者确认Vercel变量已导入，采集未开启、发布待授权。最新实施状态见[实现与本地验证](./实现与本地验证.md)。

## 1. 目标、范围与确认状态

仅网站所有者可以查看全站及页面访问数据，了解流量规模、趋势、页面表现、单次访问时长、IP 属地及设备构成。

### 1.1 已确认的产品要求

- 网站级、页面级 UV 和 PV 总览。
- UV/PV 双折线趋势图，支持时间和全站/页面筛选。
- 页面 UV/PV 分组柱状排行榜，只显示所选时间内有访问数据的页面。
- 时长分布采用柱状图，按**单次访问**统计，纵轴是访问次数。
- 属地、设备分开两张柱状图。
- 时间快捷项：近7天、近1个月、近3个月、近半年、近一年、有史以来；支持日历日期范围。
- 单一管理员密码登录，不做注册、用户管理、角色系统或第三方登录。
- 登录页简单；统计页采用中性浅灰背景、白色卡片、小号深灰 `jiaxuan` 字标。
- 左侧仅“数据概览”，底部为“打开主站”和“退出登录”。

以下参数由本方案补齐，并非用户逐项确认过的参数。开发按此草案设计，修改时同步本文件及验收用例。

| --- | --- |

### 1.3 本期范围边界

本期采集浏览、有效停留、属地和设备，提供上述统计。点击转化、阅读进度、课程完成、访问路径、来源分析、用户画像、会话回放、数据导出和后台内容管理不纳入本期。

历史上没有采集的时长等信息不能补回；现有 Vercel Analytics 的历史数据不自动混入新统计，两套工具的访客口径可能不同。

## 3. 页面与筛选规则

### 3.1 全局筛选

- 时间和统计范围改变后，总览、趋势、时长、属地、设备同步更新。
- 页面排行始终比较全站页面，**只受时间筛选影响**；展示明确说明。
- 范围选项为“全站”及具体页面名称；首页是独立的“首页”，不是全站别名。
- 页面选项仅列当前所选时间内有浏览数据的页面。时间切换导致已选页面无数据时保留当前选项并标记“该范围暂无访问”，允许用户切回全站，不静默换范围。
- 选项可搜索页面名，重名页面同时展示路径。首次完成初始化后没有数据时至少保留“全站”。
- 日历输入包含开始日与结束日；结束日不可早于开始日，不能选择未来日期。

### 3.2 时间边界与粒度

快捷项按自然日计算并含今天：近7天=7天；近1个月=30天；近3个月=90天；近半年=180天；近一年=365天。界面显示实际日期范围，避免把它理解为完整自然月。

查询将北京时间日期转换为 UTC 半开区间 `[开始日00:00, 结束日次日00:00)`，今天的数据截止服务端生成响应的时刻，不计未来。数据库时间以 UTC 保存。

“有史以来”从正式生产采集的首次有效数据开始；尚未有数据时显示暂无数据。前端不能把未采集的历史日期表现为已确认的零访问。

趋势粒度自动建议：≤31天按日、32–180天按周、>180天按月；允许改为按日/周/月，选择过细导致超过400个点时提示调整粒度。周从北京时间周一开始，月按自然月；两端不足完整周/月的点只包含实际选择范围。

### 3.3 图表及状态

| 模块 | 指标/规则 | 展示 |
| --- | --- | --- |
| 总览 | 所选范围 UV、PV | 2张数字卡片，标注所选时间内 |
| 趋势 | 各时间桶 UV、PV | 蓝色UV、绿色PV，单一次数轴；悬停显示区间、两项数值 |
| 页面排行 | 所选时间各页面 UV、PV | 横向分组柱；默认按PV降序，支持UV排序；并列时按路径排序 |
| 时长分布 | 全站为会话次数，页面为页面访问次数 | 5档柱状图，注明“单次访问有效停留时长” |
| 属地 | 所选范围去重访客构成 | 横向柱状图，以国家+一级行政区作分组键 |
| 设备 | 桌面端、手机、平板、未知的UV | 独立柱状图 |

排行容器可滚动或分页，覆盖所有有数据页面，不静默只截取前10名。地域图同样支持查看完整条目；不混淆“未知”与剩余条目的“其他”。

已覆盖采集的时间桶没有浏览时显示0；请求失败、存储未配置或采集故障显示异常状态，不能替换成0。加载时保留骨架；筛选请求只展示最后一次选择的结果，取消/忽略过期响应。

桌面优先，窄屏卡片按单列排列、图表保持可读；筛选组件可换行。图表提供文字说明/数据表，数值不能只靠颜色区别。

## 4. 指标口径

### 4.1 页面及访客身份

一个规范化路径代表一个页面：保留大小写语义、统一项目约定的尾斜杠、去掉 query 和 hash；同页的目录锚点跳转不新增 PV。动态路由按实际内容路径区分，如每课、每篇文章各有独立名称。

浏览器首次访问生成随机匿名 `visitor_id`，保存在站点本地存储，同一浏览器同一站点复用。服务端使用独立秘密对其做 HMAC，统计库保存 `visitor_key`，不用IP作为UV身份。清缓存、隐私模式、换设备会产生不同身份，UV是估算的浏览器访客量，不是真实自然人数。存储不可用时使用当次内存身份，标注覆盖限制，不拼接指纹兜底。

跨日/跨月UV需要稳定身份键。身份密钥轮换会改变去重结果，轮换前需制定过渡方案，不能像管理员登录密钥一样随意轮换。

### 4.2 PV 与 UV

- 首次成功进入可统计页面产生1个PV；实际页面路由切换、刷新、离开后重新进入各产生新PV。
- 每次页面浏览分配唯一 `page_view_id`；网络重试、React重复挂载、心跳均不增加PV；数据库唯一约束防止重复写入。
- 页面UV：查询时间内访问该路径的 `COUNT(DISTINCT visitor_key)`。
- 全站UV：查询时间内访问任意可统计路径的 `COUNT(DISTINCT visitor_key)`，不能累加页面UV或每日UV。
- 全站PV等于该时间内可统计页面PV之和。首次访问只产生1个PV，不另加“网站访问PV”。
- 趋势每点UV在该桶内去重，所以趋势UV之和可能大于总览UV。

### 4.3 单次网站访问与单次页面访问

网站“单次访问”是一段匿名访客会话，跨页面、跨午夜可延续；连续30分钟无有效活动后结束，之后的活动属于新会话。多标签页同一访客合并为同一网站会话，服务端负责会话归属，不能由每个标签独立创建网站访问次数。

页面“单次访问”对应一次 `page_view_id`，进入该页开始，离开/刷新结束。返回同页产生新访问；在页面停留但空闲30分钟后继续活动，也开始新的页面访问与网站会话，而不是沿用旧计时。后台返回时长分布的 `unit=site_session` 或 `page_visit`。

页面只在可见且获得焦点、最近5分钟有有效活动时计时。进入页面、恢复焦点、点击、键盘、触摸、滚动是活动信号；后台隐藏或失焦立即暂停，5分钟无交互后暂停，重新活动后继续。鼠标轻微移动不作为唯一活动信号。该定义可能低估静静阅读，属于明确的估算取舍，不声称精确阅读时间。

页面时长使用单调计时及连续有效区间，不用“关闭时间减打开时间”。网站时长取该会话全部有效区间的**并集**，不累加重叠标签页时间。

关闭/崩溃时可能丢失最后一段，心跳降低影响；不能把最后心跳至30分钟超时全部算成停留。无有效时长但有效PV的访问计为0秒，进入首档；校验失败的计时记录不得伪装为0，应计入采集质量日志。

### 4.4 时长分布的时间筛选

按访问开始时间决定归属：网站会话使用会话开始时间，页面访问使用页面访问开始时间，二者都在所选区间内才进入对应分布。早于所选区间开始的会话不进入该区间的会话时长分布，即使它在区间内产生PV；所以时长分布次数不等于UV或PV。

对选中访问，只累计截至所选结束边界/当前时刻的有效区间，不把下一天的活动算进今天。跨边界的区间要裁剪。未结束访问计入截至当前的暂定时长，页面注明“进行中的访问时长可能变化”。

单位为秒，档位边界为 `[0,60)`、`[60,3600)`、`[3600,7200)`、`[7200,10800)`、`[10800,+∞)`。总次数等于五档之和；同一访客可以产生多次访问，分别落入不同档。

### 4.5 地域与设备

属地只保存国家及一级行政区编码，不展示/保存原始访客IP、精确坐标；设备仅保存桌面/手机/平板/未知类别，不保存完整UA。首次事件服务端解析后供本次访问复用。

Vercel生产请求提供国家、一级地区等地理请求头；使用可信部署入口中的数据，并将编码映射为显示名称。国内显示省级地区，v1海外按国家展示；国内国家已知但省区缺失时显示“中国（省区未知）”，国家未提供或无法识别时显示未知，不能猜测。IP代理及运营商出口会影响估算。本地开发不能验证真实生产IP属地。[Vercel请求头文档](https://vercel.com/docs/headers/request-headers)

所选范围内每名访客以**首次符合范围的页面浏览**上的属地、设备作代表，各只归入一类，保证每张完整分布图的UV之和等于总览UV；同一访客后续变化不会在同一张图重复累计。

## 5. 采集流程与接口契约

### 5.1 公共采集组件

在公共布局接入一次，监听可统计页面路径及文档标题就绪；按当前路由注册规则创建页面访问。页面切换时关闭前一个访问、补交有效区间，再创建新浏览。query/hash变化不触发浏览。

采集仅针对生产主域名的有效公共页面；本地、Preview、后台、登录、API、404/错误页、静态资源排除。管理员已登录浏览主站默认排除；浏览器提供DNT时尊重退出采集，保留覆盖说明。匿名访问不依赖管理员Cookie。

现有Vercel Analytics继续作为独立数据源，不进入本后台的指标计算；部署时检查两套采集不会误发相同本模块事件。

### 5.2 数据提交

`POST /api/analytics/collect`，JSON或beacon可用的JSON文本，统一接受受限请求体。事件类型为 `page_view`、`activity_batch`、`page_end`。

公共字段：`schema_version`、`event_id`、`visitor_id`、`page_view_id`、`tab_id`、规范化`path`、`client_time`。活动批次还包括区间及批次序号。客户端不提交可信IP、属地、权限、UV、PV总数等聚合值。

- 接口对类型、长度、大小、合法路径、时间范围、区间顺序做白名单校验；v1每批≤50段、请求体≤16KB。
- 服务端时间作为PV归属时间；活动区间通过客户端单调时间及服务端接收时间对齐，客户端时钟明显偏移时裁剪/拒绝并记录质量原因。
- 心跳提交累计/区间更新，不新增PV。事件及批次幂等键唯一；相同数据重试不重复累计时长。
- 采集失败不得影响主站加载或导航；客户端队列有界（最多100个事件），重试使用退避、同一事件ID，队列溢出记丢失，不无限增长。
- 离开时使用beacon等尽力发送，不保证送达。服务端处理并发更新、乱序及结束后迟到事件；建议只接受24小时以内补交，并按原始有效访问裁剪，不能把补交当新访问。
- 响应成功为204；格式无效400；不允许来源403；限流429；存储未配置/不可用503。仅返回状态，不泄露读取接口或密钥。
- 同源校验、受信主域名、请求大小限制、持久化限流一起实施；不能认为客户端公共埋点可以完全防伪，异常流量单独记录，不进入正常图表。

### 5.3 查询

`GET /api/admin/analytics?from=YYYY-MM-DD&to=YYYY-MM-DD&scope=site|page&path=...&granularity=day|week|month&rankBy=pv|uv`。

服务端鉴权、验证范围、绑定SQL参数并返回同一快照的：`summary`、`trend`、`pageRanking`、`durationDistribution`、`regionDistribution`、`deviceDistribution`、`meta`。排行仍使用全站范围，只共享时间；聚合规则不由前端再加工推算。

`meta`包含实际UTC/北京时间边界、采集起点、粒度、生成时间、时长单位及估算提示。本次页面选项并入同一鉴权统计响应的 `pages` 字段，按时间返回；数据无记录返回合法空数组，数据库错误返回503而不是假零。

后台及查询响应 `Cache-Control: private, no-store`；权限过期返回401，界面清除统计展示并跳转登录，不在公开静态缓存中保存个人后台数据。

| `ANALYTICS_STORAGE` / `ANALYTICS_DATA_MODE` | 存储类型及test/production隔离模式 |
| `ADMIN_PASSWORD_HASH` | 带盐密码哈希及参数，不是明文或可逆加密密码 |
| `ADMIN_SESSION_SECRET` | 管理员随机会话令牌的HMAC校验密钥 |
| `ANALYTICS_ID_SECRET` | 匿名访客身份映射密钥，独立于登录密钥 |
| `ANALYTICS_ENABLED` | 服务端采集开关，生产启用前显式配置 |

秘密不加`NEXT_PUBLIC_`前缀，不进入客户端包、Git或文档示例。通过本地交互脚本生成密码哈希，不将明文密码作为命令行参数或发进聊天；本地`.env.local`保持忽略，生产在Vercel项目环境变量配置。缺少关键配置时后台关闭访问，采集报告不可用，不采用默认密码。

## 7. 登录与权限

### 7.1 页面和流程

登录页：小号`jiaxuan`字标、返回主站链接；居中窄白卡片，“私人数据后台”“请输入管理员密码”；密码框（默认隐藏、可切换显示）；“登录”；小字“仅限管理员访问”。不做账号、邮箱、注册、第三方登录和找回密码入口。

密码为空不提交，提示“请输入密码”；提交期间按钮显示“登录中…”并禁用重复提交；支持Enter提交。失败显示“密码不正确”；限流显示“尝试次数过多，请稍后再试”；服务不可用显示“暂时无法登录，请稍后重试”，不展示配置或数据库细节。登录错误保留焦点，错误文本可被辅助技术识别。

打开后台时未登录→登录页；正确密码→签发新会话→统计页。已有有效会话打开登录页→统计页。returnTo仅允许本站后台白名单路径，防止跳转到外站；默认`/admin/analytics`。退出为POST，服务端撤销会话并清Cookie，旧令牌不能再读取数据。

### 7.2 服务端保证

- 密码采用带盐慢哈希；本次实现使用Node内置scrypt，N=131072、r=8、p=1、64字节输出，减少额外依赖，参数遵循OWASP推荐。不是直接SHA-256哈希。[密码存储依据](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)
- 登录成功生成至少32随机字节的不可预测令牌，只把校验摘要存进数据库；原令牌只写入Cookie，不放URL或localStorage。
- Cookie生产设置Secure、HttpOnly、SameSite=Strict，限制域与路径；每个后台页面和数据接口独立验证会话摘要、到期与撤销状态，不能只靠菜单隐藏或中间件。[会话管理依据](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)
- 登录、退出等写操作校验Origin并执行同源/CSRF防护；限流在密码哈希运算前完成。现有进程内Map限流不能承担跨实例登录防护。
- 改密码时重新生成HASH并轮换ADMIN_SESSION_SECRET、重新部署，使全部管理员会话失效；密码重置通过所有者控制的部署配置完成。
- 不在日志记录密码、Cookie原令牌、数据库连接串或原始访客IP；密码校验、数据库读取均不向公共客户端暴露。

## 8. 新页面接入规范

1. 新公共页面使用公共布局中的采集组件，不在页面内重复安装SDK。
2. 提供稳定规范路径和明确页面名称；动态页面由注册函数生成，如“第17课 · Skill”。
3. 路径匹配支持当前文章、Agent课、SQL课等动态内容；未注册但有效的公共页面兜底使用安全文档标题/路径，不能漏计，开发检查提示补全名称。
4. `/admin`、API、404、错误页、资源路径默认排除；重定向只统计最终页面，不额外计中间地址。
5. URL参数/锚点默认不区分页面；未来确需区分业务子页时必须调整注册与统计文档，不直接上传完整URL。
6. 新页面验收检查首次PV、站内切换PV、名称、时长暂停/恢复；一般页面无需手写埋点。
7. 老页面下线后保留历史页面名称与访问记录，不因为路由删除而从历史排行榜消失；改名不拆成新页面身份。
8. 页面大改或迁移路径要决定是否为同一页面；重定向旧路径的统计映射在注册表显式维护，不靠模糊标题合并。
