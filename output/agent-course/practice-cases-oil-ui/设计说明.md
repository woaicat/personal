# 实战案例页 · 第二轮视觉探索

## 任务与约束

- 页面类型：持续更新的 Agent 产品设计与开发案例阅读库。
- 首屏任务：先看到一篇值得深入阅读的本期推荐，再按主题发现其他案例。
- 沿用课程的顶部导航、蓝色强调和同页切换意图；新增的插图需有统一画法。
- 案例简介按 3–4 行的真实阅读长度设计，不以一句话概括。
- 交付为静态、可离线查看的设计小样与对比页；未接入项目路由、真实资料或筛选逻辑。
