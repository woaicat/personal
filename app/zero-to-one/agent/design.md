# 「从 0 到 1 设计一个 Agent」课程详情页设计规范

> 用途：作为 `/zero-to-one/agent/[lessonId]` 后续详情页的共同视觉基线。
>
> 本文约束无直接教学含义的界面元素：页面框架、间距、字号、颜色、图标、边框、圆角与数据呈现方式。每一课的正文结构、图示、案例、练习和表格可以不同，不要求套用同一种内容板块。

## 1. 设计原则

1. **内容可以不同，阅读节奏必须相同。** 每课可以使用概念图、选择题、流程、表格或公式；但同等级标题、段落、卡片和区块之间的距离保持一致。
2. **详情页是一套模板，不是一课一套缩放比例。** 不为某一课单独缩小标题区、要点区、正文区或全局强调色。
3. **内容过宽时扩展容器，不压小文字。** 宽表格使用局部横向滚动；不以小于正文辅助字号的方式塞入更多列。
4. **图标表达模块级别，不表达课次。** 同一层级的图标尺寸、描边、颜色和与文字的间距固定；课程内容不同不改变其视觉权重。

## 2. 通用页面骨架（所有课程一致）

课程详情页统一采用以下顺序：

```text
返回课程目录
课程标题区
本课要点
正文内容区（模块数量与类型可变）
本课产出 + 下一课
右侧本课大纲 / 继续学习（桌面端）
```

桌面端固定为正文 + 右侧目录双栏；移动端为单栏，隐藏右侧目录。正文内容区不要求每课拥有相同的首个模块，但首个模块开始位置必须遵守本规范的章节间距。

## 3. 基线令牌

### 3.1 颜色与边界

| 用途 | 令牌 / 值 |
| --- | --- |
| 主强调色 | `--lesson-accent: #318355` |
| 深强调色 | `--lesson-accent-dark: #256743` |
| 浅强调底色 | `--lesson-accent-soft: #edf8f0` |
| 极浅强调底色 | `--lesson-accent-pale: #f6fbf7` |
| 分隔线 | `--lesson-line: #e3e9e5` |
| 正文标题 | `#171e2c` |
| 正文 | `#536070` |
| 卡片描边 | `#dce7df` 或 `#dfe7e1` |
| 常规圆角 | `8px` |

不得仅为某一课覆盖上述颜色令牌。只有状态（正确、错误、警示）可以使用语义颜色。

### 3.2 字体层级

| 元素 | 字号 | 行高 / 字重 |
| --- | --- | --- |
| 课程标题 `h1` | `clamp(2rem, 3.5vw, 2.75rem)` | `1.16 / 700` |
| 正文章节 `h2` | `1.1rem` | 默认 / `700` |
| 模块标题 `h3` | 沿用已有模块层级 | 不因课次降级 |
| 导语、正文 | `0.83rem` | `1.72` |
| 课程副标题 | `0.92rem` | `1.65` |
| 元信息 | `0.78rem` | `1.5` |
| 卡片标题 | `0.76rem` | `1.35` |
| 卡片说明 | 不低于 `0.67rem` | `1.45` |
| 表格正文 | 不低于 `0.73rem` | `1.45` |
| 表头 | `0.78rem` | 默认 |

除表格的极短辅助说明外，不新增孤立的 `px` 字号。所有课程使用 `var(--font-sans)` 及现有中文字体回退。

### 3.3 间距

| 位置 | 规范 |
| --- | --- |
| 页面布局上下内边距 | `38px 0 72px` |
| 标题区内边距 | `22px 0 15px` |
| 要点区内边距 | `14px 0 22px` |
| 正文章节内边距 | `31px 0 35px` |
| 章节标题下方 | `8px` |
| 正文模块前间距 | `17–19px` |
| 卡片组间距 | `12px` |
| 页脚上内边距 | `27px` |

同一课可以因内容需要添加导语、提示或数据模块，但不能通过覆盖 `.lessonLayout`、`.lessonHeader`、`.lessonKeyPoints` 或 `.lessonSection` 来整体压缩页面。

## 4. 非内容元素规范

### 4.1 图标

- 使用同一套 Lucide 图标、现有 `1.7–1.8` 描边风格和主强调色。
- “本课要点”图标固定为 `20px` 圆形容器，内部图标 `13px`。
- 普通信息卡图标使用 `24–26px`；紧凑数据行可使用 `19–20px`，但不能因课次随意变色或改变描边。
- 图标与标题间距保持 `9–11px`；不将图标仅作为装饰而与同层卡片使用不同尺寸。

### 4.2 卡片与提示框

- 常规信息卡：`border: 1px solid #dce7df`、`border-radius: 8px`、`padding: 12px`、最低高度 `62px`。
- 紧凑数据卡允许更低高度，但仍使用 `8px` 圆角、同色描边、相同标题字号和强调色。
- 提示框使用极浅强调底色与左侧强调线，圆角统一为 `8px`；仅在内容确实需要提示、结论或边界时使用。
- 公式、说明、练习反馈与普通卡片共享边框、圆角和字号阶梯，不自成另一套微缩组件。
- 选择题复用 `_components/LessonChoiceQuestion.tsx`，保证选项、选中状态、正确/错误反馈和无障碍状态在所有课程中一致。

### 4.3 表格

- 表格外层负责 `overflow-x: auto`；表格本身可以设置合理 `min-width`，优先保证可读性。
- 单元格使用 `8px 10px` 内边距，正文最小 `0.73rem`，表头 `0.78rem`。
- 课程页不因列数多而把表格缩到 `0.59rem`；移动端允许仅表格区域横向滚动，不允许整页横向溢出。

## 5. 第 4 课对齐改造清单

第 4 课保留“任务卡、公开 benchmark、评估维度、步骤轨道、评分表、公式”这些内容，只调整无内容含义的视觉属性：

1. **删除整页压缩覆盖。** 移除 `.fourthLessonPage` 对 `.lessonLayout`、`.lessonHeader`、`.lessonKeyPoints`、`.lessonSection` 及各 `#section-*` 的间距覆盖，使其直接使用通用间距。
2. **使用通用强调色。** 移除 `.fourthLessonPage` 的颜色令牌覆盖，复用所有详情页默认绿色。
3. **导语回归正文样式。** `.lessonFourIntro p` 使用 `0.83rem / 1.72 / #536070`；保留段落内容，但不使用单独的 `13px`、更深文字色和更紧行高。
4. **任务卡对齐普通信息卡。** `.lessonFourTaskCard` 使用 `8px` 圆角、`12px` 内边距和至少 `62px` 高度；图标提升至普通信息卡尺度，标题与说明沿用卡片字体层级。
5. **评估维度卡对齐卡片系统。** 保持三列结构，但使用同一描边、`8px` 圆角、`12px` 内边距及普通图标间距；不要因三列排版额外缩小字体。
6. **评分表恢复可读字号。** 将 `.lessonFourTable` 正文调至不低于 `0.73rem`、表头 `0.78rem`、单元格 `8px 10px`；为表格设置足够的 `min-width`，通过现有横向滚动容器解决窄屏问题。
7. **统一收束模块。** benchmark 说明、公式框和表格说明统一到 `8px` 圆角与同一字号阶梯；不再保留第 4 课独有的 `7px` 与超小说明字。

## 6. 新课实现检查清单

- [ ] 未覆盖页面级颜色令牌、标题区、要点区或章节级通用间距。
- [ ] `h1`、副标题、元信息、本课要点、章节标题和页脚与第 1、2 课使用同一规格。
- [ ] 图标尺寸与颜色由组件层级决定，而非由课次决定。
- [ ] 新卡片、提示框、公式框、反馈框使用 `8px` 圆角和统一边框。
- [ ] 宽表格采用局部滚动和足够最小宽度，而不是降低正文可读性。
- [ ] 桌面端与移动端均无整页横向溢出。
- [ ] 内容模块可以不同，但章节开始位置、模块前后留白和底部收束保持同一阅读节奏。
